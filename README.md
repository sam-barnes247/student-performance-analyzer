# Student Performance Analyzer

## 📌 Project Overview

This project analyzes student academic performance using Python and Pandas.

The program calculates statistics, identifies high-performing students, assigns performance categories, sorts students by score, and creates a bar chart to visualize their scores.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

## 📊 Analysis Performed

- Average student score
- Highest and lowest scores
- Pass rate
- Score statistics
- Students scoring 70 or higher
- Students sorted by score
- Performance categories
- Student score visualization

## 📁 Project Files

- `student_analysis.py` — Main Python analysis program
- `student_data.csv` — Generated student dataset
- `README.md` — Project documentation

## 🎯 Goal

The goal of this project is to practice data analysis, data visualization, and Python programming fundamentals.
